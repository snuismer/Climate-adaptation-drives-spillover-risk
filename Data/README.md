## Respository contents:
- The `Clean` subdirectory contains cleaned village-level data with derived
information on *Brucella* force of infection into the human population
- The `Raw` subdirectory contains raw village-level data
- The `Sensitivity` subdirectory contains randomly generated replicates of
livestock average lifespan values and the resulting MLE estimates for each randonly drawn lifespan for each parameter combination.
- The `MLE Results` subdirectory contains parameter estimates for 10 randomly drawn starting values for each parameter combination.
