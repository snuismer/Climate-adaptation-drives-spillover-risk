# Human adaptation to climate change drives increased brucellosis spillover risk

This repository includes data, R scripts, and Mathematica files required to reproduce the analyses reported in the manuscript *Human adaptation to climate change drives increased brucellosis spillover risk*. 

## The repository contains the following folders:
- Data on livestock herd composition, livestock seroprevalence, and the force of *Brucella* spillover into the human population for the 15 study villages in Marsabit and Kajiado counties, Kenya. This folder also contains results from simulated data and parameter estimates used to produce visual outputs. 
- R scripts to test for relationships between expected livestock herd lifespan and the force of *Brucella* spillover into the human population, to fit the mathematical model to livestock seroprevalence data using maximum likelihood, and generate simulated data to test parameter recovery.
- *Mathematica* file deriving basic mathematical results and performing numerical analyses.
- Visual outputs of various analyses.
