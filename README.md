# Human adaptation to climate change drives increased brucellosis spillover risk

This repository includes data, R scripts, and Mathematica files required to reproduce the analyses reported in the manuscript *Human adaptation to climate change drives increased brucellosis spillover risk*. 

## The repository contains the following specific items:
1. Data on livestock herd composition, livestock seroprevalence, and the force of *Brucella* spillover into the human population for the 15 study villages in Marsabit and Kajiado counties, Kenya (XXX.sv)
2. R script to test for relationships between livestock lifespan and the force of *Brucella* spillover into the human population (XXX.R)
3. R script to fit the mathematical model to livestock seroprevalence data using maximum likelihood (XXX.R)
4. *Mathematica* file deriving basic mathematical results and performing numerical analyses (XXX.nb)
